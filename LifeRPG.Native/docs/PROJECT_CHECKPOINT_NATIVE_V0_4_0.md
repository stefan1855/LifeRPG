# LifeRPG Native v0.4.0 Checkpoint

- 分支：`v0.4-action-task-statistics`
- 本次任务：行动任务统计看板第一阶段
- 已支持总任务数统计
- 已支持待开始、进行中、已完成、已取消任务统计
- 已支持逾期任务、今日到期、本周到期统计
- 已支持总任务经验值、已完成任务经验值统计
- 已支持按四象限统计任务数量和经验值
- 已支持按成长属性统计任务数量和经验值
- 已支持在新增、编辑、完成、取消、删除、关联行为记录后刷新行动任务统计
- 已支持在删除行为记录导致解除关联后刷新行动任务统计
- 已支持在备份恢复后刷新行动任务统计
- 本轮没有新增数据库字段
- 本轮没有引入图表组件
- 本轮没有修改图片逻辑
- 本轮没有修改行动任务与行为记录关联逻辑
- 当前仍使用 WPF 原生 UI 展示统计数据
- `v0.4.1-statistics-polish` 将在此基础上继续打磨统计口径和可读性，不新增数据库字段
