# LifeRPG RC3：图片清理、AI/MCP 与系统通知

日期：2026-10-31。三个板块已完成应用实现与隔离验收，测试候选包为 2.3.0-rc.3。腾讯会议业务查询按用户要求保留白名单待办；其余下列通过项均有实际测试记录。

## 使用方式与设计

### 图片整理

入口：封印核心 → 图片整理。

1. 扫描数据库中的记录图片、任务图片和头像引用；兼容历史绝对路径，并保守保护大小写不同的同名引用。
2. 仅列出超过 24 小时、未被引用的常见图片文件。近期文件保留；目录、链接、重解析文件与未知类型跳过。首次没有图片目录时返回空清单。
3. 用户勾选清单、确认后移入数据根目录 `.image-cleanup/<批次>/files`。清单先落盘，再移动文件；中途失败可以按实际已移动文件恢复。
4. 隔离图片可以按批次恢复，已有同名文件时拒绝覆盖。隔离区不计入正常备份，迁移数据目录时会一起复制。
5. 永久删除需查看批次并输入“永久删除”；删除前再次核对引用与文件状态。只有永久删除才释放这些文件占用的空间。没有自动定时删除；系统盘数据目录不执行清理操作。

扫描结果是建议清单。执行前会重新扫描引用和核对文件大小、修改时间；数据维护与应用数据读写共用互斥保护。迁移期间写入明确返回稍后重试，迁移后重试进入新目录。

备份同步补强：核对快照全部图片引用，先写临时归档，成功完成后才发布 ZIP。缺图时明确失败，不发布“成功但不可恢复”的备份。恢复覆盖记录图、任务图和头像的路径重映射。若当前状态已经缺图，恢复前额外保存数据库与可读图片及缺图清单，再允许恢复有效备份，避免“因为缺图而无法恢复”。

### AI 与 MCP

- AI 连接、任务解析、装备命名、属性教练、周期复盘均经本机真实网关验证，串行使用 `glm-5.3-flash`。测试发送合成数据，没有把真实账号资料传给模型。
- 修复阻塞客户端在异步运行时内引发 panic、请求一直等待的问题；耗时命令统一通过 `spawn_blocking` 执行，后台异常返回错误。
- AI 任务保留带时区的截止时间；“明天下午三点”实测得到 `2026-11-01T15:00:00+08:00`，编辑器改为本地日期时间。
- 复盘读取所选周期内最近记录的正文摘要与任务；不再把工具清单冒充外部数据。当前流程为用户手动执行工具 → 查看结果 → 保存为行为记录 → 复盘读取记录，不是模型自动执行任意工具。
- MCP 核对 JSON-RPC 响应 ID，处理服务端 ping、通知和工具清单分页。编辑参数使用可逆的 JSON 数组，兼容旧空格格式，支持目录末尾反斜杠、空参数与引号。
- MCP 默认启用 UTF-8。修复旧 Python 用 GBK 解码中文响应，导致真实抖音查询报 `list index out of range` 的问题。目录权限造成的 Git Bash 启动错误通过使用现有正常 Python 运行环境区分验证。
- 已知服务返回文本形式的业务错误也会标为失败。失败结果不能存为成功记录或获得经验。抖音只接受账号主页或账号分享链接，拒绝推荐首页与不支持的链接字符，去掉主页跟踪参数。

真实服务结果：腾讯会议握手探测 10 个工具通过；之前的只读查询返回 500125，来源 IP 不在企业应用白名单。用户明确选择稍后处理，未修改后台白名单、服务脚本或远程服务器。抖音握手探测 1 个工具，并用用户提供的个人主页完成真实只读查询，确认返回账号标识、粉丝和作品字段；证据只记录字段存在和成功状态，不保存个人资料值。

联调依赖：腾讯会议使用项目临时环境中的 Python 3.14、MCP 2.3.0 与官方 SDK 1.0.10；抖音使用已有正常 Python。正式配置需填写自己可用的 Python 完整路径、脚本参数和环境变量。测试配置不自动写入正式程序。

### 系统通知

入口：封印核心 → 窗口与快捷 → 到期提醒、发送测试通知、刷新状态。

- 开关即时保存，独立于快捷键配置；应用运行时每 30 秒检查一次，退出后不检查。
- 同一任务、同一截止时间只提交一次；已完成、未来与无效截止时间跳过。每轮最多 3 条，提交失败后至少间隔 60 秒再重试。
- 直接检查 Windows 通道并同步提交，记录提交结果、最后错误与重试次数；修复此前插件排队后即返回成功、底层失败却被标为已提醒的问题。
- 便携模式使用系统已有通知通道，不安装快捷方式或注册新应用身份。通知标题是 LifeRPG，Windows 来源可能显示 PowerShell，设置页已说明。
- 测试按钮会查询本次通知是否进入 Windows 通知记录。记录确认和横幅展示分别表述；系统勿扰、用户通知设置可能影响横幅。
