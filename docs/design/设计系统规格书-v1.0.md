## 二、字体系统

### 2.1 字体选型

| 用途 | 推荐字体 | 备选 | 风格 |
|------|---------|------|------|
| 标题/面板名 | 自定义装饰衬线体 | Cinzel / UnifrakturMaguntia | 奇幻哥特 |
| 正文/说明 | 旧体衬线 | MedievalSharp / Cormorant Garamond | 古典手稿 |

| 中文（全部） | 站酷文艺体 / 思源宋体 Heavy | — | 须有刻印质感 |

### 2.2 字号层级

| 层级 | 字号 | 字重 | 示例 |
|------|------|------|------|
| H1 全局标题 | 36-42px | Bold/ExtraBold | "角色仪表盘" |
| H2 面板标题 | 18-22px | Bold | "暗影契约" |
| H3 大数值 | 28-40px | Bold | "125,760" |

| Caption 小字 | 10-13px | Regular | 时间戳 |
| Button 按钮 | 14-16px | Medium/Bold | "编辑角色资料" |

### 2.3 字距

- 标题：`letter-spacing: 0.08em ~ 0.12em`（微拉开）
- 数字：`letter-spacing: 0.04em`（紧凑）
- 正文：默认

## 三、布局网格

### 3.1 总体结构（三栏）

设定设计基准：**1460 × 920**（用户窗口偏好）

```
┌──────────┬──────────────────────┬─────────────┐
│ 左面板    │      中面板           │  右面板      │
│ 28%      │      39%             │  33%        │
│ 人物卡    │  经验区 + 暗影契约环   │ 装备+日志    │
│          │                      │             │
│          │                      ├─────────────┤
│          │                      │ 右下功能面板  │
│          │                      │ 17%高       │
└──────────┴──────────────────────┴─────────────┘
```

| 面板 | X 起止 | Y 起止 | 宽 | 高 |
|------|--------|--------|-----|-----|
| 顶栏标题 | 29%-71% | 0%-10% | 42% | 10% |
| 左面板（人物卡） | 0%-28% | 12%-100% | 28% | 88% |
| 中面板（核心） | 28%-67% | 12%-88% | 39% | 76% |
| 右上面板（装备+日志） | 67%-100% | 12%-83% | 33% | 71% |
| 右下功能面板 | 67%-100% | 83%-100% | 33% | 17% |
| 刷新按钮 | 85%-97% | 2%-6% | 12% | 4% |

| 面板 | 内边距 | 说明 |
