## 发现与处理

| 问题 | 处理 |
|---|---|
| 快速添加只传标题，真实后端属性为 general，与详细新建 mind 不同 | 两条路径共用默认值；快速请求显式传入 Q2 / mind / 25，界面显示“重要不紧急 · 心智 +25 EXP” |
| 浏览器模拟接口补出 mind，掩盖真实后端默认值 | 模拟的空属性默认改为 general；增加真实 SQLite 结算回归 |
| AI 解析期间新输入的任务文本被迟到响应清空 | 只清除与原请求相同的文本，增加异步回归 |
| RC6 改名与原主题不一致 | 恢复行动契约、哥特声学、外接神域等已有命名 |
| AI/MCP 一律折叠改变原先入口方式 | 恢复原有展开方式；音效及任务细项保留收拢 |
| 折叠缺少原规范 8.1 / 8.2 的反馈 | 增加悬停微亮、箭头旋转与内容下滑；隐藏内容使用 inert，不进入 Tab 顺序；遵守减少动画偏好 |
| 关于页“零联网”与可选 AI/MCP 功能不符 | 改为客观的“本地存储” |

仪表盘三栏布局、角色立绘、六维、装备与日志未改动；沿用黑铁、古铜、绿火及原有金属边框。没有新增设置系统或修改数据库结构。
