# 2026-10-31 第一轮修复

本轮修改活跃工程 app，历史归档及既有便携包未改动。

## 已处理

- 备份测试恢复到独立数据库，不再恢复或删除实际数据目录。
- 恢复先保护当前数据；拒绝路径越界、重复条目、缺失数据库与损坏数据库；使用 SQLite backup 事务替换数据库，不再直接覆盖 WAL 数据库文件。
- 图片存储相对文件名，兼容历史绝对路径；异地恢复为图片分配新名称，避免覆盖当前图片。
- 数据迁移使用数据库一致性快照；禁止新旧目录互相包含，拒绝覆盖目标已有数据库，验证后切换配置。
- 行为记录与经验结算使用事务；补齐心智属性经验，历史数据只补齐一次；保留记录原始事件日期。
- 删除已完成任务同步回滚经验，更新删除提示。
- 示例内容使用一次性初始化标记，已有装备/技能/地点也视为已有内容。
- 逾期比较、今日任务统计使用统一时间语义；默认象限经验与界面一致。
- AI、MCP、图片导入与备份等耗时命令改为异步调度；AI 关闭时不再先启动 MCP。
- MCP 参数保留 Windows 路径、空格、空参数和引号；编辑后可往返保存。
- 开机缓存固定程序目录，取消回落系统临时目录；配置通过临时文件和原子替换保存。
- 到期通知加入后台检查与按任务截止时间去重；快捷键注册失败保留旧绑定。
- 记录与图库加入分页、缩略图，点击预览再读取大图。
- 弹窗挂到 body，限制尺寸，自动聚焦、限制 Tab 焦点范围、关闭后返回焦点；未保存内容关闭前提示。
- 挂件头尾固定、待办滚动；经验条分母修正；待办优先展示较早截止任务。
- 空装备槽打开库存选择器；小窗口装备页改为纵向布局。
- 按显示器缩放后的尺寸约束窗口；窄屏导航收成图标栏。
- 面板正文背景降噪，降低亮边，正文改用清晰的中文字体；保留金属边框、哥特标题与绿火主色。
- 实际没有窗口透视能力的设置改称界面亮度；增加减少动态效果的系统偏好支持。
