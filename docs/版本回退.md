## 回到这次简化之前

先保存当前尚未提交的源码修改，再执行：

```powershell
git fetch origin --tags
git switch -c restore-rc5 v2.3.0-rc.5-source
```

这会从 RC5 标签创建一个新分支，保留主分支上的后续提交。正常构建入口在 `app/`，构建与便携打包步骤见 `HANDOVER.md`。

## 数据与本地文件

Git 保存源码、必要素材、依赖锁文件、构建脚本、设计规格和经过筛选的报告。密钥、便携配置、数据库、图片证据、运行缓存、构建目录和原始联调结果不上传。

源码回退不等于数据恢复。需要回到较早数据时，使用应用的备份与恢复功能；便携 ZIP 保存在本地 `dist/`，相应哈希记录已入库。
