# 任务录入与设置页简化

日期：2026-11-02。活跃工程：`app/`。版本：`2.3.0-rc.6`。

> 状态：待审快照，不是验收完成版。后续只读核查发现快速添加未指定成长属性，实际后端落为 general，而详细新建默认 mind；浏览器模拟接口补成 mind，掩盖了这项行为差异。新增折叠未完整实现原规范的悬停与展开动画，命名和默认折叠范围也未完成设计一致性审查。本次 Git 入库保留此状态便于追溯，没有顺带修改产品代码。简化前基线标签为 `v2.3.0-rc.5-source`。

## 使用变化

- 任务顶部输入框默认直接添加：输入标题，按回车或点“添加任务”。沿用后端现有默认象限、属性及经验；不请求 AI，也不需要先开表单。
- “AI 解析”独立为可选按钮，解析后仍打开表单供核对。原有四象限看板与编辑、完成、撤销、删除入口保留。
- 点“更多设置”可带入已输入的标题；新建表单默认只展示标题与可选截止时间，详情、象限、属性、经验及分类折叠。编辑已有任务或核对 AI 解析结果时展开细项。
- 新建表单带入的标题仍保留在顶部输入框；未修改时直接关闭，修改后沿用既有未保存提示。保存成功清除相同的顶部输入，切回待办及全部象限，便于找到新任务。
- 设置页的音效、AI 军师、外接工具 MCP 默认收起，标题处显示开关状态或服务数量。展开后保留现有配置和操作。删除音效合成、数据库格式等与日常操作无关的技术说明。
