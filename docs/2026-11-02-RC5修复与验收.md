# LifeRPG RC5 修复与验收

日期：2026-11-02。活跃工程 `app/`；候选包 `dist/LifeRPG-portable-v2.3.0-rc.5.zip`。RC4 保留。本轮未提交 Git，未改动正式数据或腾讯会议白名单。

## 修复内容

- **配置保护**：区分不存在、读取失败及 JSON 损坏。损坏时不再读取旧版系统目录配置；数据库访问和配置写入被阻止，启动页提供配置恢复入口。恢复前复制保存原件，再导入有效配置或选择数据目录。所有配置变更通过同一个互斥锁执行读取、合并、原子替换，保存失败回传前端。
- **经验一致性**：任务结算在 IMMEDIATE 写事务内读取角色、任务和事件；记录创建、修改、删除及任务撤销使用写事务。重复完成保持首次 CompletedAt。已完成任务的经验和成长属性由前后端锁定，其他说明字段仍可修改。
- **装备一致性**：装备保存和穿戴事务化；已穿戴装备换槽会卸下目标槽原装备。有效穿戴视图按每角色每槽最近穿戴选取一件，快照与属性聚合共用该集合。历史重复槽位显示保留/卸下预览，执行前创建可恢复备份，然后修复。
- **异步与编辑器**：MCP 请求、返回结果和转存名称绑定执行上下文，迟到响应不进入另一个工具。AI 建任务、装备命名、复盘增加编辑会话检查。弹窗以表单快照比较 dirty，包含附件和加成数组；还原原值可直接关闭，保存中禁用关闭与内容编辑。
- **统计与图库**：连续活跃从完整日期集合计算，独立于近30天图表。图库按图片分页、使用时间和ID稳定排序、返回 hasMore；加载错误有重试入口。
- **头像与 UI**：透明头像保留 PNG alpha，普通旧 JPEG 兼容；完整显示/铺满裁切保存到角色。导航支持展开文字并持久化。正文与辅助字号提高；宽窗口三栏，窄窗口使用紧凑角色卡和首屏待办，六维、装备日志可折叠。

## 接口与兼容

- `app_state` 增加 `configError`；新增 `config_recover(source?,dataDir?)`。普通配置读取仍返回既有设置结构，异常返回可读错误。
- 配置增加 `navExpanded`，默认 false。
- 新增 `equip_conflicts` 与 `equip_repair`；修复结果包含备份信息及卸下数量。
- 新增 `image_gallery(limit?,offset?)`，返回 `{items,hasMore}`；既有记录接口保留。
- 角色增加 `avatarFit`，数据库兼容迁移默认 contain；新增 `rpg_set_avatar_fit(mode)`，允许 contain/cover。
- 新增有效装备数据库视图；原有表与文件引用继续保留。配置恢复原件保存在 exe 同级的 `liferpg.config.recovery-*.json`。

最终发布程序使用 `D:\LifeRPG-QA-20261031` 下的独立副本、合成数据与用户已授权的 Win32 交互方式验收，包含：

- 损坏配置原件不被覆盖、坏恢复文件被拒绝、有效配置导入、指定数据目录恢复。
- 对隔离配置文件施加并恢复读取拒绝 ACL；另以 Windows 共享锁模拟读取失败。两种情况均进入恢复界面并阻止业务数据库访问。只读配置保存失败时原件保留。
- 后端并发任务/记录账本、重复完成日期、已完成任务编辑拒绝、换槽互斥、历史冲突有效加成、60天活跃回归。

- 仅移除附件后关闭会提示；输入后恢复原值可直接关闭；透明头像 alpha 与显示模式保存通过。
- 最新51条记录无图、较早记录有图时，图库仍返回图片；分页 hasMore 检查通过。
