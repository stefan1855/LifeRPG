# RC8 参考贴图核查与 UI 接入

用户授权先核查素材，符合原始设计后直接改动 UI。本轮以 `docs/design/设计系统规格书-v1.0.md` 和 `assets/reference-ui-v1/source/reference.png` 为视觉依据，以 RC7 业务源码及素材提交 `b2c5486` 为起点。

## 核查结论

110 张 ready 贴图的文件哈希、PNG 解码及制作来源复核通过。选择其中 57 张用于运行时，保留无损像素及透明通道，图标按真实内容裁去多余空白；3 套字体转为离线 WOFF2，保留全部字形与各自 OFL 许可证。详见 `asset-audit.json` 及 `app/src/assets/reference/manifest.json`。

原始切片带有参考图中的文字和遮挡，仅供核对，没有导入运行界面。淘汰的火焰初稿也没有接入。边框与按钮固定边角、延展中段；进度条独立裁切填充，宝石端帽保持形状。去字、补绘和延展是新制作内容，不宣称它们与原图隐藏像素相同，也不宣称响应式界面已达到 100% 像素一致。

## 实际改动

- 外框、角色卡、场景背景、黑铁古铜面板、按钮状态和进度条改用核查后的贴图。
- 恢复参考图对应的无面术士；头像选择、清除、显示方式及资料编辑继续走原有接口。
- 契约环使用六类独立符文、荆棘节点框、中心魂火徽记和法阵。主题名下保留体魄、心智等实际属性含义，点击仍进入原成长属性页。
- 十二个装备槽按参考图恢复单列，替换原先重复的角色剪影为专用装备背景；已穿戴状态仍由真实快照决定。
- 最近变化使用六类日志徽记，首页展示六条，可打开完整日志并继续分页加载。
- 待办结算保留在主三栏下方。技能、人物、地图入口继续对应既有功能，没有编造不存在的契约或声望系统。
- 中文标题和正文使用不同字重的 Noto Serif SC；紧凑等级和百分比使用 Roboto Condensed。任务、设置、装备、引导及小窗的公共字体、按钮和边框统一到这套材质。
- 修正实测发现的日志撑高整列、契约文字越界和响应式容器规则未生效问题。

## 验证范围

`browser-checks.json` 使用实际 Vue 页面及合成 Tauri 响应检查：

- 1672×941、1460×920 为三栏；1250×850、1068×700 为双栏；760×560、480×700 为单栏，实际滚动容器无横向溢出。
- 六符文、十二单列槽位、全部实际显示图片加载、基准窗口三栏完整显示。
- 角色资料保存、100→125 条日志分页、待办任务结算与刷新、符文/装备/技能入口导航。
- 长角色名与说明、空日志、空任务、0% 与 100% 经验；任务和设置页面加载。
- 捕获浏览器异常和 Vue 经 console.error 上报的异常，最终均为零。

另有原先 8 项前端回归全部通过；Vite 生产构建与 Tauri Release 构建通过。便携包门禁 0 个 Low 标签、3 个 ZIP 条目。

截图使用合成数据，是实际页面渲染，不是静态美术组合。此轮未启动正式实例、未修改正式配置或数据库；浏览器检查不等于原生桌面端到端验收。没有重跑后端业务、高 DPI、跨显示器、通知或真实 AI/MCP 联调；RC7 既有结果保持原范围。

本地复验：先启动开发服务器，再执行 `python -X utf8 scripts/tests/reference-ui.browser.py`；Python 需要 Pillow（素材脚本）、fontTools（素材脚本）、websocket-client（浏览器检查）及本机 Chromium 浏览器。生产构建可设置 `LIFERPG_UI_TEST_URL` 指向静态服务器。测试只使用自建临时浏览器配置和内置合成接口。
